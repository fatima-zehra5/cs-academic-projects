# Smoothify — Product Landing Page
A responsive smoothie shop website built with HTML5 and CSS3.

## Features
- Animated homepage — fruits merge into smoothie on load
- Multi-page layout — Home, Menu, About, Contact
- Responsive design with CSS Grid
- Hover effects and smooth transitions
- Custom color theme — pink & coral palette

## Pages
- index.html — Animated homepage with fruit scene
- menu.html — Smoothie menu with product cards
- about_contact.html — About us and contact info
