# University Digital Lost & Found System
A C++ console application for campus-wide item tracking
using file handling and string matching algorithms.

## Features
- Report lost items with name, description, location
- Report found items
- View all lost and found records
- Smart matching algorithm — matches lost to found items
- Auto-removes matched items from lost records
- Clear all data option

## How It Works
- Data stored in text files (lost_items.txt, found_items.txt)
- Matching based on name and location character comparison
- Minimum 3-character match threshold for name and location
- Menu-driven console interface
