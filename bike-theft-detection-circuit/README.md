# Bike Theft Detection Circuit
An electronic anti-theft circuit designed and simulated
in Multisim using sensor-based trigger logic.

## Features
- Sensor-based trigger detection
- Alert system activation on unauthorized movement
- Simulated and validated in Multisim 14
